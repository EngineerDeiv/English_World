# Global Rules

## Objective

Process every entry listed under Unknown Words and move it to the correct category file within ./English_Notes.

The goal is to keep the knowledge base organized while preserving the original content exactly as written.

## Workflow

1. Read Unknown Words.
2. Identify the correct category.
3. Locate the destination file.
4. Insert in alphabetical order.
5. Remove from Unknown Words.
6. Preserve all existing content.
