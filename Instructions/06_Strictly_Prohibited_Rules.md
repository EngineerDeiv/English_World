# Strictly Prohibited Rules

The AI must never:

- Rewrite content.
- Correct grammar.
- Improve wording.
- Translate entries.
- Expand explanations.
- Summarize content.
- Modify examples.
- Change meanings.
- Change capitalization.
- Change punctuation.
- Merge categories without instruction.
- Never delete existing categorized entries.
- Never Read and add anything from .Trash or other resource.
- Never delete the table of unknown Words, leave it empty but never delete it.

Only classify and relocate.
