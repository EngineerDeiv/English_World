# Formatting Rules

## Preserve Existing Tables

Never:

- Delete tables
- Recreate tables
- Rename columns
- Reorder columns
- Modify table structure

## Alphabetical Ordering

Inside each category file:

- Insert new entries alphabetically.
- Preserve existing records.
- Preserve table format.

## Unknown Words

Unknown Words acts only as a temporary staging area.

After categorization:

- Move the entry.
- Remove it from Unknown Words.
